From Metal to Markup

A look at how typesetting changed from hand-set type to code.

Old Fashioned Typesetting

Before computers, a printer built each page by hand. A worker picked small metal letters one at a time and placed them in a frame. Every space, line, and margin was set by hand. If there was a mistake, the worker had to fix the metal by hand. It was slow, but the printer had full control over how the page looked.

Desktop Publishing

Desktop publishing moved this work onto a computer. A person could now type text, drag it around the page, and change the font with a click. Mistakes were easy to fix. The page on the screen looked like the page that would be printed, so the designer could see the result right away.

HTML and CSS

HTML and CSS work in a different way. HTML describes what each part of the page is, like a heading, a paragraph, or a footer. CSS describes how those parts look, like their color, font, and spacing. The page is not fixed in size. It changes to fit a phone, a laptop, or a large monitor.

Compare and Contrast

All three methods have the same goal, which is to make text easy to read. Typesetting and desktop publishing both make one fixed page, while HTML and CSS make a page that can change shape. In typesetting, the printer controls every detail by hand. In desktop publishing, the software helps with the layout. With HTML and CSS, the browser builds the page from the rules the writer gives it. Typesetting also costs the most time and materials, while a web page can be changed in seconds and shared with anyone.
