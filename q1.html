Emphasis and strengthened text

When I write a sentence, I can put stress on one word to change how it sounds, like "I said tomorrow." If a warning really matters, I mark it as important, like do not delete this folder.

Separating content from presentation

Explanation

I would pick <em> and <strong> over <i> and <b> because they tell the browser what the text means, not just what it looks like. If I use <i>, I am only saying "slant this text," and that could be for a book title, a foreign word, or nothing in particular. With <em>, I am saying this word has stress. A screen reader can use that to change its voice, and a search engine can tell which text is important. Also, if I want a different look later, like red text instead of bold, I can change it in CSS and leave the HTML alone. That keeps the content and the style in separate places.
